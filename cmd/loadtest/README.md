# HTTP 接口压力测试工具

这是一个用于对 injective-explorer API 进行 HTTP 接口并发压力测试的工具。它可以帮助评估 API 在高并发场景下的性能表现。

## 功能特性

- 支持多接口并发压力测试
- 支持自定义并发数和测试时长
- 支持自定义总请求数
- 详细的性能统计输出（QPS、延迟分布等）
- 支持动态参数生成（随机分页、随机地址等）
- 支持跳过数据预加载（使用默认测试数据）
- 支持 Verbose 模式查看详细请求信息

## 安装

```bash
go build -o loadtest main.go
```

## 使用方法

### 基本语法

```bash
./loadtest [选项]
```

### 命令行参数

| 参数 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `-url` | - | `http://localhost:8000` | 服务器基础 URL |
| `-c` | - | `10` | 并发数（同时工作的 goroutine 数量） |
| `-d` | - | `0` | 测试持续时间（如：30s, 5m, 1h） |
| `-n` | - | `0` | 总请求数（0 表示使用 duration） |
| `-timeout` | - | `30s` | 单个请求的超时时间 |
| `-v` | - | `false` | 详细输出模式（显示失败的请求） |
| `-endpoint` | - | 空 | 指定测试的接口路径（空表示测试所有接口） |
| `-skip-data-load` | - | `false` | 跳过数据预加载，使用默认测试数据 |

### 使用示例

**示例 1：测试 30 秒，观察性能指标**

```bash
./loadtest -url http://localhost:8000 -c 50 -d 30s
```

**示例 2：测试 1000 个请求**

```bash
./loadtest -url http://localhost:8000 -c 20 -n 1000
```

**示例 3：指定测试单个接口**

```bash
./loadtest -url http://localhost:8000 -c 10 -d 1m -endpoint /api/v1/block/latest
```

**示例 4：跳过数据预加载（快速启动）**

```bash
./loadtest -url http://localhost:8000 -c 100 -d 5m -skip-data-load
```

使用 `-skip-data-load` 参数时，工具将直接使用内置的默认测试地址和区块范围，跳过从 API 加载真实数据的步骤。这对于以下场景特别有用：

- **离线测试**：在没有运行完整的 injective-explorer 服务时进行测试
- **快速验证**：只想快速验证工具本身是否正常工作
- **默认测试**：使用预设的测试数据即可满足测试需求

**示例 5：详细输出模式**

```bash
./loadtest -url http://localhost:8000 -c 5 -n 100 -v
```

## 测试的接口

工具会自动测试以下 API 接口：

| 接口名称 | 路径 | 参数类型 |
|----------|------|----------|
| 健康检查 | `/api/v1/health` | 无 |
| 最新区块高度 | `/api/v1/block/latest-height` | 无 |
| 最新区块列表 | `/api/v1/block/latest` | 分页参数 |
| 按高度获取区块 | `/api/v1/block/by-height` | 区块高度 |
| 最新交易列表 | `/api/v1/transaction/latest` | 分页参数 |
| 交易统计 | `/api/v1/transaction/stats` | 无 |
| 24小时失败交易 | `/api/v1/transaction/failed-24h` | 分页参数 |
| 账户信息 | `/api/v1/account/info` | 地址参数 |
| 账户余额 | `/api/v1/account/balances` | 地址参数 |
| 账户交易 | `/api/v1/account/transactions` | 地址+分页参数 |

### 动态参数说明

- **分页参数**：随机生成页码（1-10）和每页数量（10/20/50/100）
- **区块高度参数**：从有效区块范围内随机选择
- **地址参数**：从测试地址列表中随机选择

## 工作原理

1. **数据加载阶段**：默认从 API 加载最新的区块高度和真实交易地址作为测试数据
2. **并发测试阶段**：启动指定数量的 goroutine，每个 goroutine 随机选择接口进行测试
3. **统计汇总阶段**：收集所有请求的结果，计算 QPS、延迟等性能指标

## 注意事项

1. 测试前请确保目标服务器已启动
2. 建议先使用小并发量进行测试，逐步增加
3. 长时间测试建议使用 `-d` 参数配合适当的并发数
4. 生产环境测试请注意控制并发数，避免影响正常服务
5. 使用 `-skip-data-load` 可以跳过数据加载，但测试数据可能不够真实

## 与性能测试框架的区别

本工具是一个独立的轻量级测试工具，适用于：

- 快速验证 API 基本功能
- 简单的并发性能评估
- 开发阶段的本地测试

对于更复杂的性能测试需求（如压测报告、梯度加压等），建议使用专业的压测工具如：
- [wrk/wrk2](https://github.com/wg/wrk)
- [k6](https://k6.io/)
- [JMeter](https://jmeter.apache.org/)
